📊 Sales & Funnel Analysis Dashboard (Excel Project)

🚀 Overview

This project analyzes sales data and simulates a user conversion funnel to understand customer behavior and improve conversion rates.

🎯 Objective

- Analyze revenue trends and customer behavior
- Track funnel stages: views → add to cart → purchase
- Identify drop-offs in the conversion process

🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Charts & Dashboards

📈 Key Metrics

- Total Revenue
- Conversion Rates (View → Cart → Purchase)
- Product Performance Trends

🔍 Insights

- Major drop-off observed between add-to-cart and purchase stage
- High views did not always translate to high purchases
- Certain categories performed significantly better than others

💡 Improvements Suggested

- Improve checkout experience to reduce cart abandonment
- Optimize product pages to increase add-to-cart rate
- Focus marketing on high-converting categories

📌 Outcome

This project highlights the importance of funnel analysis in improving conversion rates and optimizing sales performance using data-driven insights.
